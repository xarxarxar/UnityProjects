# 阶段 5 第二批：武器脚本低风险清理

日期：2026-06-16  
目标：在不改变武器玩法、数值、协程时序和刷新流程的前提下，整理当前可刷新武器脚本的注释、Inspector 提示和结构分区。

## 本批范围

本批只处理当前可刷新武器和共享子弹：

| 文件 | 处理内容 |
|---|---|
| `Assets/人物信息/所有武器/标配/BiaoPei.cs` | 增加中文 XML 注释、`[Tooltip]`、`#region` 分区 |
| `Assets/人物信息/所有武器/奥丁/AoDing.cs` | 增加中文 XML 注释、`[Tooltip]`、`#region` 分区 |
| `Assets/Scripts/Knief.cs` | 增加中文 XML 注释、`#region` 分区 |
| `Assets/人物信息/所有武器/子弹/VideoGameBulletBase.cs` | 增加中文 XML 注释、`#region` 分区 |

没有改动：

1. 武器数值。
2. 子弹速度。
3. 子弹伤害。
4. 射击间隔。
5. 协程等待时间。
6. `SpawnWeapons()` 调用位置。
7. 武器拾取条件。
8. 子弹命中和回收规则。
9. Prefab、Scene、Inspector 绑定。

## 风险说明

| 风险点 | 等级 | 说明 |
|---|---|---|
| 增加 `[Tooltip]` | 低 | 不改字段名、访问级别和序列化字段引用 |
| 增加 XML 注释 | 低 | 只影响代码阅读和 IDE 提示 |
| 增加 `#region` | 低 | 只影响代码折叠和结构阅读 |
| 未改玩法语句 | 低 | 关键射击、命中、回收和刷新调用已逐项核对 |

## 建议验证点

1. 标配能被角色拾取，并按原节奏发射 4 发子弹。
2. 奥丁能被角色拾取，拾取后减速，射击结束后恢复速度。
3. 小刀能被角色拾取，持续旋转，命中后造成 10 点伤害并给持有者加大招点。
4. 小刀超时消失后能继续刷新武器。
5. 子弹命中角色后由武器回调回收，命中墙体后自动回收。
