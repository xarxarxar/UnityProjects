## 新增工具说明

### `VideoGameAimUtility`

用于处理武器、投射物、技能表现常见的瞄准计算。

| 方法 | 作用 |
|---|---|
| `GetDirection(startPosition, targetPosition)` | 返回从起点指向目标点的单位方向。 |
| `AimZAxisAtTarget(root, startPosition, targetPosition, angleOffset)` | 让物体绕 Z 轴朝向目标点。 |
| `GetVerticalFlipScale(root, xScale, yScale, zScale)` | 根据当前 Z 轴旋转，决定武器是否需要上下翻转。 |
| `ReverseAngleOffset` | 当前标配、奥丁武器美术使用的 180 度反向偏移。 |

推荐用法：

```csharp
VideoGameAimUtility.AimZAxisAtTarget(
    weaponRoot,
    rolePosition,
    targetPosition,
    VideoGameAimUtility.ReverseAngleOffset);

weapon.localScale = VideoGameAimUtility.GetVerticalFlipScale(weaponRoot, 1.8f, 1.8f);
Vector3 direction = VideoGameAimUtility.GetDirection(shootPos.position, targetPosition);
```

### `VideoGameTargetUtility`

用于处理角色目标选择。

| 方法 | 作用 |
|---|---|
| `GetRandomOther(roles, self)` | 从角色列表中随机选一个不是自己的角色。 |

推荐用法：

```csharp
BaseRole target = VideoGameTargetUtility.GetRandomOther(
    VideoGameManager.instance.circleRoles,
    this);
```

当前 `BaseRole.GetRandomOther(BaseRole self)` 仍然保留，外部原有调用方式不变。

## 修改原因说明

| 修改点 | 原因 |
|---|---|
| 新增 `VideoGameAimUtility` | `BiaoPei` 和 `AoDing` 中瞄准、角度、上下翻转、子弹方向计算重复，适合先抽成无状态工具。 |
| 新增 `VideoGameTargetUtility` | 随机选择其他角色是新增英雄常用能力，独立出来后可复用。 |
| `BiaoPei` 使用瞄准工具 | 去掉重复计算，保留原射击流程、数值和回调。 |
| `AoDing` 使用瞄准工具 | 去掉重复计算，保留原减速、射击流程、数值和回调。 |
| `BaseRole.GetRandomOther` 委托工具类 | 保持原公开方法不变，同时让目标选择能力可被其他脚本直接复用。 |
| 同步 `Assembly-CSharp.csproj` | 当前命令行编译使用显式文件列表，新工具脚本需要加入工程文件列表。 |

## 风险说明

| 风险点 | 等级 | 说明 |
|---|---|---|
| `BaseRole` 方法体变短 | 中低 | 触碰了核心脚本，但公开方法、随机算法、随机次数、返回规则保持一致。 |
| 武器瞄准工具化 | 低 | 抽出的是原有数学计算，角度偏移、缩放值、子弹方向保持一致。 |
| `Assembly-CSharp.csproj` 是生成文件 | 低 | Unity 可能在刷新工程时重写该文件；这不影响 `Assets` 下真实脚本。 |
| 新工具类未挂载到场景 | 低 | 静态工具类不需要 Inspector 绑定，不改变场景结构。 |

## 建议人工验证点

1. 进入 `VideoScene` 后，标配拾取、瞄准、射击、命中、回收表现保持一致。
2. 奥丁拾取后角色减速、连续射击、瞄准翻转、命中、结束恢复速度保持一致。
3. 所有依赖 `otherBaseRole` 的英雄或武器仍能正常找到目标。
4. 新增英雄时，可以优先使用 `VideoGameTargetUtility.GetRandomOther` 获取随机目标。
5. 新增武器时，可以优先使用 `VideoGameAimUtility` 处理瞄准和翻转。

## 使用说明

这次新增的是静态工具类，不需要挂载组件，不需要改 Inspector。  
继续从 `VideoScene` 运行即可。

后续新增武器时，如果只是普通朝向目标射击，可以优先复用 `VideoGameAimUtility`。  
后续新增英雄时，如果只是从当前存活角色里随机找一个敌人，可以优先复用 `VideoGameTargetUtility`。
