# 阶段 5 第四批：子弹命中与回收边界整理

日期：2026-06-16  
目标：在不改变通用子弹命中、回调和回收表现的前提下，整理 `VideoGameBulletBase` 内部结构，明确哪些边界后续不能随手改。

## 本批范围

本批只处理：

| 文件 | 处理内容 |
|---|---|
| `Assets/人物信息/所有武器/子弹/VideoGameBulletBase.cs` | 提取 Tag 常量、拆分初始化/角色命中/墙体命中私有方法、补充边界注释 |
| `Codex/阶段5-第四批-diff.patch` | 记录本批代码 diff |

没有改动：

1. `Init` 方法签名。
2. 子弹速度计算方式。
3. `Rigidbody2D` 获取方式。
4. 忽略 Tag 的判断方式。
5. 命中角色后的回调触发方式。
6. 命中角色后默认不自动回收的行为。
7. 命中墙体后先触发 `OnBulletHitWall`，再 `Recycle()` 的顺序。
8. 回调字段 `OnBulletHitRole`、`OnBulletHitWall` 的保留方式。
9. Prefab、Scene、Inspector 绑定。

当前使用 `VideoGameBulletBase` 的主要脚本：

|---|---|

因此本批没有修改回调清理、自动回收、忽略 Tag 和墙体回收策略。

## 代码整理点

新增常量：

```text
RoleTag = "Role"
WallTag = "wall"
MissingRigidbodyWarning = "父物体没有 Rigidbody2D 组件！"
```

新增私有方法：

| 方法 | 作用 | 行为边界 |
|---|---|---|
| `GetBulletRoot` | 获取 `transform.parent` | 不缓存，保持每次读取父物体 |
| `SetBulletRootRotationAndActive` | 设置根物体旋转并激活 | 保留先旋转再激活 |
| `ApplyBulletVelocity` | 获取 `Rigidbody2D` 并设置速度 | 保留每次 `Init` 时 `GetComponent<Rigidbody2D>()` |
| `TryHandleRoleHit` | 处理非发射者角色命中 | 命中角色后仍不自动回收 |
| `HandleWallHit` | 处理墙体命中 | 保留先触发墙体回调再回收 |

## 已确认保留的关键顺序

初始化顺序：

```text
direction = dir.normalized
this.speed = speed
bulletRoot = transform.parent
bulletRoot.position = startPos
_baseRole = baseRole
this.tags = tags
bulletRoot.rotation = Quaternion.Euler(0, 0, angle)
bulletRoot.gameObject.SetActive(true)
Rigidbody2D rb = bulletRoot.GetComponent<Rigidbody2D>()
rb.velocity = direction * this.speed
```

命中顺序：

```text
ShouldIgnoreTag(collision)
→ 如果需要忽略，return
→ 如果是非发射者 Role，触发 OnBulletHitRole
→ 命中 Role 后不由 VideoGameBulletBase 自动 Recycle
→ 如果是 wall，触发 OnBulletHitWall
→ Recycle()
```

回收顺序：

```text
StopAllCoroutines()
transform.parent.gameObject.SetActive(false)
```

## 本批刻意不改的点

| 未改项 | 原因 |
|---|---|
| 不清空 `OnBulletHitRole` / `OnBulletHitWall` | 可能影响复用对象的调用方预期，必须单独审查 |
| 不让命中角色后自动 `Recycle()` | 标配、奥丁、后羿、炸弹妹、捷风、钱包都在各自回调中决定回收 |
| 不缓存 `Rigidbody2D` | 捷风会运行时给飞镖父物体添加/销毁 `Rigidbody2D`，缓存可能改变行为 |
| 不给 `_baseRole` 增加空引用保护 | 可能改变错误暴露方式，本批只整理结构 |
| 不过滤空字符串 Tag | 可能改变错误暴露方式，本批只保留原始判断 |

## 建议验证点

1. 标配、奥丁命中角色后仍然造成伤害并回收子弹。
2. 后羿小鸟仍然忽略墙体，命中角色后造成伤害和眩晕。
3. 炸弹妹导弹命中角色后回收，未命中时超时回收。
4. 捷风飞镖仍然能发射、命中、回收。
5. 钱包大狙命中角色或墙体后仍然绘制弹道。
6. 普通子弹命中 `wall` 后仍然自动回收。
