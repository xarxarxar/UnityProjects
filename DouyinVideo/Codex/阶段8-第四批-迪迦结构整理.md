# 阶段 8 第四批：迪迦结构整理

日期：2026-06-17

## 本批目标

在不改变迪迦大招玩法表现的前提下，整理 `DiJiaRole.cs` 的结构和少量重复逻辑，让后续维护持续激光类英雄时更容易看清边界。

本批不做以下事情：

- 不修改激光伤害数值。
- 不修改激光持续时间、伤害间隔、射线距离、抖动频率和抖动幅度。
- 不修改大招协程启动顺序。
- 不修改 `otherBaseRole` 的取值方式。
- 不修改 Prefab、Scene 或组件绑定。

## 代码改动说明

### 1. 清理无用引用

移除 `DiJiaRole.cs` 中未使用的：

```csharp
using System.Collections.Generic;
```

只保留当前脚本实际使用的 `System.Collections` 和 `UnityEngine`。

### 2. 提取常量

将原本散落在大招流程中的字符串和数值提取为私有常量：

| 常量 | 原值 | 用途 |
|---|---:|---|
| `WallTag` | `"wall"` | 判断激光是否命中墙体 |
| `RoleTag` | `"Role"` | 判断激光是否命中角色 |
| `IgnoreLayerYeLu` | `"YeLu"` | 激光射线排除层 |
| `IgnoreLayerWeapon` | `"Weapon"` | 激光射线排除层 |
| `CastDelay` | `1.0f` | 大招释放前等待时间 |
| `NoiseSpeed` | `5.0f` | 激光抖动速度 |
| `NoiseAmplitude` | `15f` | 激光抖动幅度 |
| `LaserDuration` | `5f` | 激光持续时间 |
| `DamageInterval` | `0.2f` | 激光伤害间隔 |
| `LaserStartOffset` | `2.5f` | 激光起点偏移 |
| `LaserDistance` | `100f` | 激光射线距离 |
| `HitDamage` | `3` | 每次命中伤害 |

这些常量只改变可读性，不改变实际数值。

### 3. 提取激光辅助方法

新增私有方法：

| 方法 | 作用 | 行为变化 |
|---|---|---|
| `GetNoisyLaserDirection` | 计算带正弦抖动的激光方向 | 无 |
| `IsLaserBlockingHit` | 判断射线是否命中墙或角色 | 无 |
| `UpdateLaserLine` | 刷新 `LineRenderer` 起点和终点 | 无 |
| `CloseLaser` | 关闭激光显示 | 无 |
| `GetLaserLayerMask` | 生成排除 `YeLu` 和 `Weapon` 的 LayerMask | 无 |
| `StopBigCoroutine` | 停止大招延迟协程 | 无 |
| `StopUpdateLaserCoroutine` | 停止激光更新协程 | 无 |

### 4. 保持目标选择行为

`BaseRole.otherBaseRole` 是一个属性，每次访问都会重新随机选择其他角色。本批没有把它改成统一缓存目标。

保留了原有访问节奏：

1. 进入 `UpdateLaser()` 时先访问一次 `otherBaseRole` 判断是否为空。
2. 随后再次访问 `otherBaseRole.transform` 保存当前激光目标。
3. 循环中继续按原逻辑访问 `otherBaseRole` 判断是否为空。

这点看起来不够整洁，但如果强行缓存会改变随机目标选择行为，所以本批刻意不改。

## 行为保持点

| 行为 | 保持方式 |
|---|---|
| 大招开始时停止旧 `bigCoro` | `Big()` 仍先停止旧协程 |
| 大招开始时关闭旧激光 | `Big()` 仍会关闭 `LineRenderer` |
| 延迟后播报大招 | `BigCoro()` 仍等待 `1.0f` 后广播 |
| 激光期间角色停速 | `UpdateLaser()` 仍在目标确认后调用 `SetSpeed(0)` |
| 正常结束后恢复速度 | 激光循环正常结束后仍调用 `SetSpeed(1)` |
| 中途目标为空时不恢复速度 | 保持原逻辑，只关闭激光并退出 |
| 射线排除层 | 仍排除 `YeLu` 和 `Weapon` |
| 命中伤害 | 仍对 `Role` 每 `0.2f` 造成 `3` 点伤害 |
| 线段更新时机 | 仍在每帧射线计算后更新起点和终点 |

## 风险说明

风险等级：中低。

原因：

- 修改了一个复杂英雄的大招协程结构。
- 没有改数值、规则、协程启动顺序、射线规则和组件绑定。
- 主要风险来自方法提取过程中是否遗漏原有早退路径。

本批特别保留了“目标为空早退时不调用 `SetSpeed(1)`”这个原有行为，因为直接修复可能改变玩法表现。

## 建议验证点

1. 迪迦释放大招前仍等待约 1 秒。
2. 战报仍显示“某某使用大招”。
3. 激光持续约 5 秒。
4. 激光有原来的左右抖动效果。
5. 命中角色时仍按间隔扣血。
6. 命中墙体时激光终点停在墙体处。
7. 激光正常结束后迪迦恢复移动。
8. 连续触发大招时旧激光和旧协程不会残留。
