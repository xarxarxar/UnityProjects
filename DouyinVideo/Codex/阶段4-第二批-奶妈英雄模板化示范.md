## 代码整理点

| 整理项 | 说明 |
|---|---|
| 删除无用 `using System.Collections.Generic` | `NaiMaRole` 没有使用泛型集合 |
| 添加 `#region 协程引用` | 统一放置 `bigCoro` |

| 添加 XML 注释 | 公开大招入口和重要私有方法有中文说明 |

## 行为保持说明

整理前的大招流程：

```text
Big()
→ 如果 bigCoro 不为空，停止旧协程并置空
→ StartCoroutine(BigCoro())
→ 等待 0.1 秒
→ 播报“使用了治疗，恢复了30点生命”
→ RecoverHp(30)
→ yield break
```

整理后的大招流程：

```text
Big()
→ StopBigCoroutine()
→ StartCoroutine(BigCoro())
→ 等待 0.1 秒
→ 播报“使用了治疗，恢复了30点生命”
→ RecoverHp(30)
→ yield break
```

`StopBigCoroutine()` 内部仍然是原来的逻辑：

```text
如果 bigCoro 为空，直接返回
否则 StopCoroutine(bigCoro)
然后 bigCoro = null
```

因此本批只是把原有代码块提取成私有方法，没有改变执行顺序。
