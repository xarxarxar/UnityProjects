## 修改原因说明

| 修改点 | 原因 |
|---|---|
| `Invoke("方法名")` 改为 `Invoke(nameof(方法名))` | 避免方法重命名后字符串失效，运行时调用顺序和延迟不变。 |
| `RoleUI` 缓存 `Camera.main` | 减少每次能量 UI 飞行动画触发时查找主摄像机。 |
| 修正 `RecoveryHp` 条件 | 原逻辑 `hp >= 0` 会把所有非负血量显示成 100；全项目未发现引用，作为明确逻辑错误修复。 |
| `RandomChoose` 缓存头像 `Image` | 避免协程末尾再次通过层级查找获取组件。 |
| 删除 `RandomChoose` 未使用 `System.Linq` | 清理 dead using。 |
| `Knief` 提取层级名和默认位置常量 | 避免字符串和坐标重复，未改变执行顺序。 |
| `VideoGameBulletBase` 使用 `CompareTag` 判断忽略 Tag | 避免读取 `collision.tag` 字符串，当前调用只传入 `"wall"`，行为等价。 |

## 风险说明

| 风险点 | 等级 | 说明 |
|---|---|---|
| `RoleUI` 缓存主摄像机 | 低 | 如果运行中动态替换 MainCamera，缓存可能仍指向旧相机；当前项目未发现动态替换相机逻辑。 |
| `RecoveryHp` 修复 | 低 | 全项目未发现调用；如果未来使用，会按传入血量显示并上限 100。 |
| `RandomChoose` 缓存 Image | 低 | 不改变选择流程，只减少重复层级查找。 |
| `Knief` 常量提取 | 低 | 字符串和坐标值保持一致，协程和触发顺序未变。 |
| `CompareTag(tags[i])` | 低 | 当前传入 Tag 为 `"wall"`；如果未来传入未注册 Tag，Unity 会报错，需要保证 tags 参数传入有效 Tag。 |
