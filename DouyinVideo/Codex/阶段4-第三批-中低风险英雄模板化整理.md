## 行为保持说明

### `BoomSisterRole`

整理前后保持：

```text
Big()
→ 停止旧 bigCoro
→ boom.Recycle()
→ StartCoroutine(BigCoro())
→ 等待 1.5 秒
→ 播报“发射了导弹”
→ 计算目标方向和角度
→ boom.Init(direction, angle, 70, transform.position, this)
→ 命中角色时 BroadcastThenDamage(..., 70, ...)
→ 命中后 boom.Recycle()
→ 等待 3 秒
→ 如果导弹父物体仍 active，则 boom.Recycle()
```

保留内容：

| 项 | 保持值 |
|---|---|
| 前摇 | `1.5f` |
| 导弹速度/伤害参数 | `70` |
| 命中伤害 | `70` |
| 回收等待 | `3` |
| 调试按键 | `KeyCode.O` + `GetKeyUp` |

### `WeiSiRole`

整理前后保持：

```text
Big()
→ 停止旧 bigCoro
→ StartCoroutine(BigCoro())
→ 等待 0.1 秒
→ Jingji.SetActive(true)
→ Jingji.transform.SetParent(null)
→ 等待 3 秒
→ 用 CircleCollider2D 半径和 lossyScale 计算范围
→ Physics2D.OverlapCircleAll(center, radius)
→ 对范围内非自己的 Role 调用 SetCanGetWeaponThenBroadcast(..., false, 10, ...)
→ SetSpeed(1.2f, 5)
→ 关闭 Jingji 并挂回自身
→ localPosition 归零
```

保留内容：

| 项 | 保持值 |
|---|---|
| 前摇 | `0.1f` |
| 范围持续等待 | `3` |
| 禁拾武器时长 | `10` |
| 自身加速 | `SetSpeed(1.2f,5)` |
| 范围检测 API | `Physics2D.OverlapCircleAll` |
