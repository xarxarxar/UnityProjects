# 修改记录

本文件用于记录所有与项目维护、重构、优化相关的改动。  
所有非游戏运行必要的文档、记录、日志都应放入 `Codex/`。

## 记录规则

1. 每次改动都追加到表格末尾。
2. 必须写清楚是否改动玩法。
3. 必须写清楚风险等级。
4. 必须写清楚建议验证点。
5. 如果只是文档改动，也要记录。

## 风险等级

| 等级 | 说明 |
|---|---|
| 低 | 不改变玩法逻辑，主要是文档、注释、命名、缓存、无用 using 清理 |
| 中 | 可能影响局部行为，需要重点验证某个角色、武器或 UI |
| 高 | 可能影响核心规则、协程时序、胜负条件、Prefab 绑定或场景结构 |
