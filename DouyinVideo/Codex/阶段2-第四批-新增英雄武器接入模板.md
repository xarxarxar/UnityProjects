## 当前可复用工具

| 工具类 | 适用场景 | 注意 |
|---|---|---|
| `VideoGameAimUtility` | 武器、投射物、部分技能朝向目标 | 只做方向、角度、翻转计算，不处理发射和命中 |
| `VideoGameTargetUtility` | 从当前角色列表中选择目标 | 如果需要固定目标、最近目标、血量最低目标，先不要硬塞进这个方法 |
| `VideoGameCombatUtility` | 固定顺序的播报、伤害、状态处理 | 根据原表现选择正确顺序方法 |

## 新增英雄模板

以下模板只作为参考，不要直接放进 `Assets` 编译。  
真正新增英雄时，复制到正式英雄目录，并替换类名、字段和技能逻辑。

```csharp
using System.Collections;
using UnityEngine;

/// <summary>
/// 英雄说明：这里写清楚英雄定位和大招效果。
/// </summary>
public class XxxRole : BaseRole
{
    #region 字段配置

    [Tooltip("大招前摇时间")]
    [SerializeField] private float bigDelay = 1.5f;

    [Tooltip("大招伤害")]
    [SerializeField] private int bigDamage = 30;

    #endregion

    #region 协程引用

    private Coroutine bigCoro;

    #endregion

    #region 大招逻辑

    /// <summary>
    /// 释放英雄大招。
    /// </summary>
    public override void Big()
    {
        if (bigCoro != null)
        {
            StopCoroutine(bigCoro);
            bigCoro = null;
        }

        bigCoro = StartCoroutine(BigCoro());
    }

    /// <summary>
    /// 执行大招流程。
    /// </summary>
    /// <returns>Unity 协程迭代器。</returns>
    private IEnumerator BigCoro()
    {
        yield return new WaitForSeconds(bigDelay);

        BaseRole targetRole = VideoGameTargetUtility.GetRandomOther(
            VideoGameManager.instance.circleRoles,
            this);

        if (targetRole == null)
        {
            yield break;
        }

        VideoGameCombatUtility.BroadcastThenDamage(
            targetRole,
            bigDamage,
            $"{RoleName}的大招对{targetRole.RoleName}造成了{bigDamage}点伤害",
            roleColor);
    }

    #endregion

    #region 开发调试入口

    private void Update()
    {
        if (Input.GetKeyDown(KeyCode.M))
        {
            UseBig();
        }
    }

    #endregion
}
```

## 新增武器模板

以下模板适合普通“拾取后朝目标射击”的武器。  
如果是持续范围、召唤物、陷阱、近战环绕武器，不要强套这个模板。

```csharp
using System.Collections;
using UnityEngine;

/// <summary>
/// 武器说明：这里写清楚武器定位、射击节奏和命中效果。
/// </summary>
public class XxxWeapon : MonoBehaviour
{
    #region 字段配置

    [Tooltip("开火音效")]
    public AudioClip shootAudio;

    [Tooltip("音源")]
    public AudioSource audioSource;

    [Tooltip("子弹数量")]
    public int bulletCount = 4;

    [Tooltip("子弹伤害")]
    public int bulletDamage = 5;

    [Tooltip("射击点")]
    public Transform shootPos;

    [Tooltip("子弹脚本")]
    public VideoGameBulletBase bullet;

    #endregion

    #region 运行状态

    private BaseRole ownerRole;
    private BaseRole targetRole;
    private int currentCount;
    private bool isAttached;

    #endregion

    #region 武器流程

    /// <summary>
    /// 将武器挂到角色身上。
    /// </summary>
    /// <param name="baseRole">拾取武器的角色。</param>
    /// <param name="target">本轮射击目标。</param>
    public void AttachToRole(BaseRole baseRole, BaseRole target)
    {
        gameObject.layer = LayerMask.NameToLayer("Weapon");
        isAttached = true;

        ownerRole = baseRole;
        targetRole = target;
        transform.parent.position = ownerRole.transform.position;
        transform.parent.SetParent(ownerRole.transform);
        currentCount = bulletCount;

        StartCoroutine(Shoot());
    }

    /// <summary>
    /// 执行射击流程。
    /// </summary>
    /// <returns>Unity 协程迭代器。</returns>
    private IEnumerator Shoot()
    {
        while (currentCount > 0)
        {
            yield return new WaitForSeconds(1f);

            Vector3 ownerPosition = ownerRole.transform.position;
            Vector3 targetPosition = targetRole.transform.position;

            VideoGameAimUtility.AimZAxisAtTarget(
                transform.parent,
                ownerPosition,
                targetPosition,
                VideoGameAimUtility.ReverseAngleOffset);

            Vector3 direction = VideoGameAimUtility.GetDirection(
                shootPos.position,
                targetPosition);

            audioSource.PlayOneShot(shootAudio);
            bullet.Init(direction, 0, 50, shootPos.position, ownerRole);
            bullet.OnBulletHitRole = OnBulletHitRole;
            currentCount--;
        }

        yield return new WaitForSeconds(0.5f);
        ResetWeapon();
        VideoGameManager.instance.SpawnWeapons();
    }

    /// <summary>
    /// 处理子弹命中角色。
    /// </summary>
    /// <param name="hitRole">被子弹命中的角色。</param>
    private void OnBulletHitRole(BaseRole hitRole)
    {
        VideoGameCombatUtility.BroadcastThenDamage(
            hitRole,
            bulletDamage,
            $"{ownerRole.RoleName}的武器击中了{hitRole.RoleName}造成了{bulletDamage}点伤害",
            ownerRole.roleColor);

        bullet.Recycle();
    }

    /// <summary>
    /// 重置武器状态。
    /// </summary>
    private void ResetWeapon()
    {
        gameObject.layer = LayerMask.NameToLayer("Default");
        transform.parent.gameObject.SetActive(false);
        transform.parent.localEulerAngles = Vector3.zero;
        currentCount = bulletCount;
        bullet.transform.parent.gameObject.SetActive(false);
        isAttached = false;
    }

    #endregion
}
```

## 工具选择建议

| 需求 | 优先使用 | 不建议 |
|---|---|---|
| 随机选一个敌人 | `VideoGameTargetUtility.GetRandomOther` | 每个英雄重新写一遍随机目标逻辑 |
| 普通武器朝目标旋转 | `VideoGameAimUtility.AimZAxisAtTarget` | 每个武器重复写 `Mathf.Atan2` |
| 普通子弹方向 | `VideoGameAimUtility.GetDirection` | 手写 `(target - start).normalized` 到处散落 |
| 先播报再伤害 | `VideoGameCombatUtility.BroadcastThenDamage` | 手写两行并可能写反顺序 |
| 先伤害再播报 | `VideoGameCombatUtility.DamageThenBroadcast` | 为了统一而改变原表现顺序 |
| 播报、伤害、减速 | `BroadcastThenDamageAndSetSpeed` | 把减速写进 `TakeDamage` 或 `BaseRole` |

## 新增英雄前 Checklist

| 检查项 | 说明 |
|---|---|
| 是否继承 `BaseRole` | 当前阶段不要新建另一套角色基类 |
| 是否只把特色大招写进英雄脚本 | 通用逻辑优先用工具 |
| 是否有协程引用 | 大招可重复释放时必须能停止旧协程 |
| 是否保留调试入口 | 调试入口放到 `#region 开发调试入口` |
| 是否复用目标选择工具 | 只有特殊目标规则才单独写 |
| 是否复用战斗结果工具 | 保持播报、伤害、状态顺序清晰 |
| 是否记录新增内容 | 新增后追加到 `Codex/修改记录.md` |

## 新增武器前 Checklist

| 检查项 | 说明 |
|---|---|
| 是否明确拾取条件 | 一般需要判断 `canGetWeapon` |
| 是否明确挂载对象 | 当前武器通常挂到拾取角色身上 |
| 是否明确瞄准方式 | 普通瞄准优先用 `VideoGameAimUtility` |
| 是否明确命中效果 | 伤害、状态、播报顺序写清楚 |
| 是否明确回收规则 | 子弹、武器本体、父物体都要复位 |
| 是否会影响 `SpawnWeapons` | 不确定时不要改刷新规则 |
