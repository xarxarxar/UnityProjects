# 阶段 5 第三批：标配 / 奥丁重复逻辑局部整理

日期：2026-06-16  
目标：在不改变标配、奥丁玩法表现的前提下，把两把枪中重复的机械步骤提取为小工具和私有方法，降低后续新增枪械的复制成本。

## 本批范围

本批只处理：

| 文件 | 处理内容 |
|---|---|
| `Assets/Scripts/Utility/VideoGameWeaponUtility.cs` | 新增武器 Transform 工具类 |
| `Assets/Scripts/Utility/VideoGameWeaponUtility.cs.meta` | 新增 Unity meta |
| `Assets/人物信息/所有武器/标配/BiaoPei.cs` | 提取常量、私有方法，并调用武器工具类 |
| `Assets/人物信息/所有武器/奥丁/AoDing.cs` | 提取常量、私有方法，并调用武器工具类 |
| `Assembly-CSharp.csproj` | 加入新工具类编译引用 |
| `Codex/阶段5-第三批-diff.patch` | 记录本批代码 diff |

没有改动：

1. 标配子弹数、射击间隔、子弹速度、伤害。
2. 奥丁子弹数、射击间隔、子弹速度、伤害。
3. 奥丁拾取后的减速和结束后的恢复速度。
4. `SetDeafult()` 方法名。
5. `SpawnWeapons()` 调用位置。
6. 子弹命中角色后的回收时机。
7. Prefab、Scene、Inspector 绑定。

## 新增工具类边界

`VideoGameWeaponUtility` 只负责以下机械动作：

| 方法 | 作用 | 不负责 |
|---|---|---|
| `AttachRootToRole` | 把武器根物体移动到角色位置并挂到角色下面 | 不设置武器状态、不设置目标 |
| `AimAndGetShootDirection` | 旋转武器根物体、翻转武器表现、返回射击方向 | 不发射子弹、不设置伤害 |
| `HideRootAndResetRotation` | 隐藏武器根物体并重置旋转 | 不刷新武器、不清状态 |
| `HideBulletRoot` | 隐藏通用子弹根物体 | 不触发命中、不清回调 |

这个工具类不保存状态，不引用 `VideoGameManager`，不调用 `Broadcast`，不调用 `TakeDamage`，不改变玩法规则。

## 标配整理点

`BiaoPei` 中新增常量：

```text
WeaponLayerName = "Weapon"
DefaultLayerName = "Default"
RoleTag = "Role"
ShootInterval = 1f
FinishWaitSeconds = 0.5f
WeaponScaleX = 1.8f
WeaponScaleY = 1.8f
BulletSpeed = 50
HitDamage = 5
```

新增私有方法：

| 方法 | 作用 |
|---|---|
| `MarkAsAttached` | 保留原来的设置 Layer、`isAttached`、`role` 顺序 |
| `SetTargetAndAttachRoot` | 保留原来的设置目标、移动父物体、设置父级、重置子弹数顺序 |
| `GetCurrentShootDirection` | 保留原来的读取角色位置、读取目标位置、瞄准、翻转、取方向顺序 |
| `HandleBulletHitRole` | 保留原来的播报、伤害、子弹回收顺序 |

已确认保留：

```text
yield return new WaitForSeconds(ShootInterval) // 1f
bullet.Init(direction,0,BulletSpeed, shootPos.position, role) // BulletSpeed = 50
VideoGameCombatUtility.BroadcastThenDamage(targetRole, HitDamage, ...) // HitDamage = 5
yield return new WaitForSeconds(FinishWaitSeconds) // 0.5f
SetDeafult()
VideoGameManager.instance.SpawnWeapons()
collision.CompareTag(RoleTag) // RoleTag = "Role"
pickerRole.canGetWeapon
AttachToRole(pickerRole, pickerRole.otherBaseRole)
```

## 风险说明

| 风险点 | 等级 | 说明 |
|---|---|---|
| 新增工具类 | 中低 | 工具类只处理 Transform 和隐藏对象，不持有玩法状态 |

## 建议验证点

1. 标配拾取后仍然发射 4 发，间隔约 1 秒。
2. 标配子弹速度和命中伤害体感不变。
3. 奥丁拾取后仍然减速到原来的表现，射击结束后恢复速度。
4. 奥丁仍然发射 15 发，间隔约 0.17 秒。
5. 两把枪结束后仍然调用 `SpawnWeapons()` 刷新下一件武器。
6. 子弹命中角色后仍然播报、伤害、回收。
