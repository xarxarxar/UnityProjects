# 新增武器指南

本指南用于后续新增武器时保持拾取、瞄准、射击、命中、回收流程清晰。

阶段 5 武器系统审查与风险分层见：`Codex/阶段5-第一批-武器系统审查与风险分层.md`。  
阶段 5 武器脚本低风险清理记录见：`Codex/阶段5-第二批-武器脚本低风险清理.md`。  
阶段 5 标配 / 奥丁重复逻辑局部整理记录见：`Codex/阶段5-第三批-标配奥丁重复逻辑局部整理.md`。  
阶段 5 子弹命中与回收边界整理记录见：`Codex/阶段5-第四批-子弹命中与回收边界整理.md`。
阶段 5 新增武器模板与 BaseWeapon 决策见：`Codex/阶段5-第五批-新增武器模板与BaseWeapon决策.md`。

## 基本原则

1. 不先重写武器系统。
2. 新武器先按现有武器流程接入。
3. 普通瞄准优先使用 `VideoGameAimUtility`。
4. 普通命中结算优先使用 `VideoGameCombatUtility`。
5. 不确定是否影响武器刷新节奏时，不修改 `VideoGameManager.SpawnWeapons`。
6. 普通枪械武器模板先从 `Codex/模板-普通枪械武器.cs.txt` 复制并改成正式脚本。
7. 特殊武器先填写 `Codex/模板-特殊武器设计卡片.md`，不要强套普通枪械模板。
8. 当前阶段暂不引入 `BaseWeapon`，先用工具类和模板约束新增武器。

## 当前可参考武器

| 武器 | 脚本 | 适合作为参考的部分 |
|---|---|---|
| 标配 | `BiaoPei.cs` | 普通拾取、挂载、瞄准、低频射击、子弹命中 |
| 奥丁 | `AoDing.cs` | 高频射击、持有者减速和收尾恢复 |
| 小刀 | `Knief.cs` | 旋转近战拾取物，不适合强套枪械模板 |

注意：  
`Hat.cs`、`YuanShiBigKnief.cs`、`CircleBullet.cs` 当前更像英雄技能生成物，不建议作为普通可刷新武器模板。

## 模板选择

| 新武器类型 | 推荐做法 |
|---|---|
| 普通拾取连射枪械 | 复制 `Codex/模板-普通枪械武器.cs.txt` |
| 射速、伤害、子弹数不同的枪械 | 复制普通枪械模板，改常量和 Inspector 字段 |
| 拾取后减速、加速或状态变化的枪械 | 复制普通枪械模板，再在具体脚本中单独处理状态 |
| 旋转近战、陷阱、召唤物、范围武器 | 先填写 `Codex/模板-特殊武器设计卡片.md` |
| 英雄专属武器或大招生成物 | 放在英雄目录，不加入普通可刷新武器模板 |

## BaseWeapon 决策

当前暂不新增 `BaseWeapon`。  
短期新增武器优先使用工具类和模板；等普通枪械数量达到 5 个以上，或多个新武器出现完全相同生命周期后，再重新评估是否做父类试点。

## 推荐流程

| 步骤 | 说明 |
|---|---|
| 拾取 | `OnTriggerEnter2D` 中判断 `Role` 和 `canGetWeapon` |
| 挂载 | 将武器父物体移动到角色位置，并设置父物体为角色 |
| 选目标 | 使用 `pickerRole.otherBaseRole` 或 `VideoGameTargetUtility.GetRandomOther` |
| 瞄准 | 使用 `VideoGameAimUtility.AimZAxisAtTarget` |
| 翻转 | 使用 `VideoGameAimUtility.GetVerticalFlipScale` |
| 发射 | 调用 `VideoGameBulletBase.Init` |
| 命中 | 在 `OnBulletHitRole` 中调用 `VideoGameCombatUtility` |
| 回收 | 关闭武器父物体、关闭子弹父物体、重置状态 |
| 刷新 | 回收后再调用 `VideoGameManager.instance.SpawnWeapons()` |

## 常用工具

### 瞄准

```csharp
VideoGameAimUtility.AimZAxisAtTarget(
    transform.parent,
    ownerRole.transform.position,
    targetRole.transform.position,
    VideoGameAimUtility.ReverseAngleOffset);
```

### 子弹方向

```csharp
Vector3 direction = VideoGameAimUtility.GetDirection(
    shootPos.position,
    targetRole.transform.position);
```

### 普通枪械挂载

```csharp
VideoGameWeaponUtility.AttachRootToRole(
    transform.parent,
    ownerRole.transform);
```

### 普通枪械瞄准和方向

```csharp
Vector3 direction = VideoGameWeaponUtility.AimAndGetShootDirection(
    transform.parent,
    transform,
    shootPos,
    ownerRole.transform.position,
    targetRole.transform.position,
    weaponScaleX,
    weaponScaleY);
```

注意：  
`VideoGameWeaponUtility` 只处理武器根物体、瞄准、翻转和隐藏，不处理伤害、播报、刷新、角色状态。玩法差异仍然留在具体武器脚本里。

### 命中结算

```csharp
VideoGameCombatUtility.BroadcastThenDamage(
    targetRole,
    bulletDamage,
    $"{ownerRole.RoleName}的武器击中了{targetRole.RoleName}造成了{bulletDamage}点伤害",
    ownerRole.roleColor);
```

### 子弹回调边界

`VideoGameBulletBase` 命中角色后只触发 `OnBulletHitRole`，不会自动回收。普通武器如果希望命中后消失，需要在回调里显式调用：

```csharp
bullet.OnBulletHitRole = (targetRole) =>
{
    VideoGameCombatUtility.BroadcastThenDamage(
        targetRole,
        damage,
        news,
        ownerRole.roleColor);

    bullet.Recycle();
};
```

命中墙体时，`VideoGameBulletBase` 会先触发 `OnBulletHitWall`，再自动 `Recycle()`。如果武器需要墙体表现，例如钱包大狙弹道，可以只在 `OnBulletHitWall` 中处理表现，不需要再次手动回收。

## 新增武器检查表

| 检查项 | 是否完成 |
|---|---|
| 武器对象 Tag/Layer 设置正确 |  |
| 拾取时检查 `canGetWeapon` |  |
| 武器挂载到拾取角色 |  |
| 子弹预制体或场景对象已绑定 |  |
| 射击点 `shootPos` 已绑定 |  |
| 命中角色后有回收逻辑 |  |
| 命中墙体后有回收逻辑，如果需要 |  |
| 武器结束后调用 `SpawnWeapons` |  |
| 所有状态字段已复位 |  |
| 已追加到 `Codex/修改记录.md` |  |

## 不建议现在做

| 不建议项 | 原因 |
|---|---|
| 新建完整 `BaseWeapon` 继承体系 | 当前武器数量少，直接替换继承体系风险偏高 |
| 改 `VideoGameManager` 武器刷新规则 | 可能改变录制节奏 |
| 改 Prefab 绑定结构 | 代码 diff 难以完整呈现影响 |
| 把所有武器一次性重构 | 容易造成多个武器同时出问题，回溯困难 |

## 验证重点

1. 武器能被角色拾取。
2. 拾取后能正确挂载到角色身上。
3. 武器能朝目标方向表现。
4. 子弹能命中角色或墙体。
5. 命中后伤害、状态、播报顺序正确。
6. 武器用完后能关闭并刷新下一件武器。
