### 1.1 GameManager.cs

public class GameManager : MonoBehaviour

#### 私有变量

1. `private static GameManager _instance;`
     – **单例实例**，供全局访问 `Instance`。
2. `private bool _isGameOver;`
     – 标记当前游戏是否结束（胜利或失败）。
3. `private int _currentRound;`
     – 当前进行到的回合编号（1–100）。
4. `private int _totalClears;`
     – 玩家累计通关次数（成功守住 100 回合的次数）。
5. `private int _startGold;`
     – 本局开局所给的初始金币数（受技能树或刻印影响）。
6. `private bool _isPaused;`
     – 标记游戏是否处于“暂停”状态，用于实现暂停/恢复功能。
7. `private float _gameSpeed = 1f;`
     – 当前游戏速度倍率，默认 1×，用于倍速功能（0.5×、1×、2× 等）。

#### 公有变量

1. `public static GameManager Instance { get; private set; }`
     – **单例公开属性**，外部可通过 `GameManager.Instance` 访问。
2. `public int TotalClears { get { return _totalClears; } }`
     – 只读属性，暴露玩家累计通关次数。
3. `public int CurrentRound { get { return _currentRound; } }`
     – 只读属性，暴露当前回合编号。
4. `public int StartGold { get { return _startGold; } }`
     – 只读属性，暴露本局开局金币数。
5. `public bool IsFailed { get; private set; }`
     – 只读属性，标记本局是否因水晶被破坏而失败。
6. `public float GameSpeed { get { return _gameSpeed; } set { _gameSpeed = Mathf.Max(0.1f, value); Time.timeScale = _gameSpeed; } }`
     – 公开属性，用于设置游戏整体倍速（同时修改 `Time.timeScale`）。最小限制 0.1f，避免归零。

#### 常量

1. `public const int MaxRounds = 100;`
     – 最大回合数。
2. `public const string SaveKey_TotalClears = "Save_TotalClears";`
     – PlayerPrefs 的存档键，用于保存/读取总通关次数。
3. `public const string Scene_MainMenu = "MainMenu";`
     – 场景名常量，用于切换到主菜单。
4. `public const string Scene_Battle = "Battle";`
     – 场景名常量，用于切换到战斗场景。

#### 属性

- `public static GameManager Instance { get; private set; }`
- `public int TotalClears { get; }`
- `public int CurrentRound { get; }`
- `public int StartGold { get; }`
- `public bool IsFailed { get; private set; }`
- `public float GameSpeed { get; set; }`

#### 成员方法（public）

1. `public void StartGame()`
     – 开始新一局战斗：初始化 `_currentRound = 0`、设置 `IsFailed = false`、通过 `SceneManager` 切换到战斗场景，并调用 `WaveManager` 启动第一回合。
2. `public void EndGame(bool success)`
     – 结束本局战斗。
     • `success = true` → 玩家成功守住 100 回合 → 累加 `_totalClears`，结算奖励，弹出胜利面板；
     • `success = false` → 玩家失败（核心水晶破坏）→ `IsFailed = true`，弹出失败面板。
     – 之后可等待玩家点击“重玩”或“返回主菜单”。
3. `public void NextRound()`
     – 进入下一回合：`_currentRound++`，如果小于 `MaxRounds` 则调用 `WaveManager.StartNextRound()`；否则调用 `EndGame(true)`。
4. `public void PauseGame()`
     – 暂停游戏：`_isPaused = true; Time.timeScale = 0;`
5. `public void ResumeGame()`
     – 恢复游戏：`_isPaused = false; Time.timeScale = _gameSpeed;`
6. `public void AddClear()`
     – 累积一条通关次数：`_totalClears++; SaveProgress();`
7. `public void SetGameSpeed(float speed)`
     – 设置 `GameSpeed` 属性（重置 `Time.timeScale`）。

#### 成员方法（private）

1. `private void Awake()`
     – Unity 生命周期回调。
     – 单例初始化：如果 `Instance == null`，则 `Instance = this; DontDestroyOnLoad(gameObject);`；否则 `Destroy(gameObject)`.
     – 初始化默认值：`_isGameOver = false; _currentRound = 0; _totalClears = 0; _startGold = 0; _isPaused = false;`。
2. `private void Start()`
     – Unity 生命周期回调，开始时调用 `LoadProgress()` 从存档读取 `_totalClears`、`_startGold` 等。
3. `private void Update()`
     – Unity 生命周期函数，每帧更新可处理“按键暂停/倍速快捷键”等：
     • 例如检测 `Input.GetKeyDown(KeyCode.Space)` → `PauseGame()`/`ResumeGame()`；
     • `Input.GetKeyDown(KeyCode.Alpha1)` → `SetGameSpeed(1f)`；
     • `Input.GetKeyDown(KeyCode.Alpha2)` → `SetGameSpeed(2f)` 等。
4. `private void LoadProgress()`
     – 从 `PlayerPrefs` 或本地文件读取 `_totalClears` 和玩家局外数据（如技能树进度、刻印等）。
5. `private void SaveProgress()`
     – 将 `_totalClears` 等存入 `PlayerPrefs` 或本地文件。
6. `private void OnApplicationQuit()`
     – Unity 回调，游戏退出时自动调用 `SaveProgress()`。
7. `private void OnDestroy()`
     – Unity 回调，若需要释放资源或取消订阅，放在此处。

#### 静态方法

- 本脚本无静态方法，主功能通过实例与生命周期方法完成。

#### 构造函数

- 不需显式定义，Unity MonoBehaviour 不建议在构造函数中写逻辑。

#### 析构函数

- 无。

#### 生命周期函数（列举）

- `Awake()`
- `Start()`
- `Update()`
- `OnApplicationQuit()`
- `OnDestroy()`

#### 成员方法（public）

1. `public void StartNextRound()`
     – 进入下一回合流程：
     • `_currentRound++`；
     • 设置 `_isSpawning = true`；
     • 检查是否有对应 `Wave_SO` 的关键波：
      \- 如果 `keyWave != null`，则依次 `StartCoroutine(SpawnBatch(type, count, interval));`；
      \- 否则调用 `GenerateRandomWave(_currentRound);`；
     – 生成完毕后重置 `_isSpawning = false`。
2. `public void ResetWaves()`
     – 重置 `_currentRound = 0; _isInKeyWave = false; StopAllCoroutines();`，清除现场怪物或等待下一局。

#### 成员方法（private）

1. `private void Awake()`
     – 单例初始化：`if (Instance == null) Instance = this; else Destroy(gameObject);`，`DontDestroyOnLoad(gameObject);`；

2. `private void Start()`
     – Unity 回调，可在这里加载 `_keyWaves = Resources.LoadAll<Wave_SO>("Configs/ScriptableObjects/Waves/").ToList();`，
     – `_poolConfig = Resources.Load<EnemyPoolConfig>("Configs/EnemyPoolConfig");`；

3. `private void Update()`
     – （可选）实时监听 `GameManager.Instance.CurrentRound`，当 `GameManager` 需要启动回合时调用 `StartNextRound()`；

4. `private void GenerateRandomWave(int round)`
     – 从 `_poolConfig.Pools` 中找到满足 `pool.RoundMin <= round <= pool.RoundMax` 的 `RoundPool`；
     – 计算 `int totalCount = Mathf.CeilToInt(10 + round * 1.5f);`（示例算法）；
     – 用 `RandomPick(pool.EnemyTypes, pool.Weights)` 获得每次生成的 `EnemyType`；
     – 循环 `SpawnOneEnemy(type)` `totalCount` 次，将怪物均匀分布（可用协程加延迟）。

5. `private IEnumerator SpawnBatch(EnemyType type, int count, float interval)`
     – 按 `count` 和 `interval`，每隔 `interval` 秒生成一只该 `type` 的怪，调用 `SpawnOneEnemy(type); yield return new WaitForSeconds(interval);`。

6. `private EnemyType RandomPick(List<EnemyType> types, List<float> weights)`
     – 传入等长的 `types` 与 `weights`，先 `float sum = weights.Sum(); float r = Random.Range(0, sum); float acc = 0;`
     – 遍历 `weights` 累加 `acc += weights[i]; if (r <= acc) return types[i];`，末尾返回最后一个。

7. `private void SpawnOneEnemy(EnemyType type)`
     – 计算 `Vector3 spawnPos = GetRandomSpawnPosition();`
     – 调用 `Vector3[] path = PathfindingHelper.FindPath(spawnPos, CoreCrystal.Instance.Position);`
     – `EnemyManager.Instance.SpawnEnemy(type, spawnPos, path);`

8. `private Vector3 GetRandomSpawnPosition()`
     – 返回在屏幕上方随机 x 位置，例如：
     \```
    float x = Random.Range(-GameArea.Width / 2, GameArea.Width / 2);
    float y = GameArea.Height / 2 + 1;

     – 核心射击流程：
      `AnimateRecoil();`  // 播放后坐力动画
      `FlashMuzzle();`   // 炮口闪光特效

      `bullet.GetComponent<Bullet>().Initialize(this, target, CurrentAttack, CritRate, CritDamage);`

      `this`：指向当前 `Tower`，供子弹拿到来源信息（如词条）。
      `target`：被击中敌人。
      `CurrentAttack`：伤害值（已包含暴击判定时加成后计算）。
      `CritRate`、`CritDamage`：用于子弹自行判定是否暴击及暴击倍率。

8. `private Enemy FindTarget()`
     – 可选辅助，将 `EnemyManager.Instance.FindNearestInRange(...)` 单独封装成此方法。
9. `private void OnDestroy()`
     – Unity 回调，当该塔销毁时：
      `_isDestroyed = true;`
      可触发额外清理逻辑，如移除词条、取消协程等。

     – 一般在 `EnemyManager.SpawnEnemy()` 中调用。
2. `public void SetPath(Vector3[] pathPoints)`
     – 传入 `PathfindingHelper.FindPath(...)` 得到的路径点列表：
     – `_pathPoints = pathPoints; _currentTargetIndex = 0; _isMoving = true;`
3. `public void TakeDamage(float damage)`
     – 处理子弹伤害：
     • 如果 `_shield > 0`，先减去护盾值：
      `_shield -= damage; if (_shield < 0) { damage = -_shield; _shield = 0; } else return;`
     • 剩余 `damage` 扣到 `_currentLife`：`_currentLife -= damage;`
     • 如果 `_currentLife <= 0 && !_isDead`，调用 `Die();`
4. `public void ApplyGlobalSlow(float factor)`
     – 收到减速升级或 Debuff 时调用：`_currentSpeed = BaseSpeed * factor;`

#### 成员方法（private）

1. `private void Awake()`
     – Unity 回调：
     – ` _spriteRenderer = GetComponent<SpriteRenderer>(); _hitCollider = GetComponent<CircleCollider2D>(); _isMoving = false; _isDead = false;`
2. `private void Start()`
     – Unity 回调，可选延迟初始化（若依赖 PathfindingHelper 等其他系统）。
3. `private void Update()`
     – Unity 每帧回调：
     – `if (!_isMoving || _isDead) return;`
     – `MoveAlongPath();`
4. `private void MoveAlongPath()`
     – 如果 `_currentTargetIndex >= _pathPoints.Length`，调用 `ReachCore(); return;`；
     – 否则以 `_currentSpeed * Time.deltaTime` 向 `_pathPoints[_currentTargetIndex]` 移动：
      `Vector3 dir = (_pathPoints[_currentTargetIndex] - transform.position).normalized;`
      `transform.position += dir * _currentSpeed * Time.deltaTime;`
     – 如果 `Vector3.Distance(transform.position, _pathPoints[_currentTargetIndex]) < 0.1f`，`_currentTargetIndex++`；
5. `private void Die()`
     – 处理敌人死亡：
     • `_isDead = true;`
     • `CurrencyManager.Instance.AddGold(RewardGold);`
     • 若拥有击杀返利词条，则在此触发额外金币返还逻辑；
     • `EnemyManager.Instance.UnregisterEnemy(this);`

1. `public void UnlockSkill(SkillBase skill)`
     – 将新解锁的 `skill` 添加到 `_unlockedSkills`，并 `skill.Initialize()`，以便冷却归零。
     – 例如：`if (!_unlockedSkills.Contains(skill)) { _unlockedSkills.Add(skill); skill.Initialize(); }`
2. `public bool EquipSkill(int slotIndex, SkillBase skill)`
     – 将 `skill` 装到指定槽位：
     – `if (slotIndex < 0 || slotIndex >= _maxSlots) return false;`
     – `if (!_unlockedSkills.Contains(skill)) return false;`
     – `_equippedSkills[slotIndex] = skill; return true;`
3. `public void CastSkill(int slotIndex, Vector3 targetPos)`
     – 释放槽位技能：
     – `SkillBase skill = _equippedSkills[slotIndex];`
     – `if (skill != null && skill.CanCast) skill.TryCast(targetPos);`

2. `private void Start()`

3. `private void Update()`

     – `_cooldownCheckTimer += Time.deltaTime; if (_cooldownCheckTimer >= _cooldownCheckInterval) { foreach (var skill in _unlockedSkills) skill.TickCooldown(_cooldownCheckTimer); _cooldownCheckTimer = 0; }`
4. `private void OnDestroy()`
     – 取消订阅所有事件（若有），清空 `_unlockedSkills`、`_equippedSkills`。

1. `public static void InitializeGrid(int width, int height)`

     – `_width = width; _height = height; _blocked = new bool[width, height];`
     – （可选缓存路径） `_pathCache = new Dictionary<string, List<Vector2Int>>();`
2. `public static void SetBlocked(int x, int y, bool isBlocked)`
     – 标记网格 `(x, y)` 是否被阻挡：
     – `if (x >= 0 && x < _width && y >= 0 && y < _height) _blocked[x, y] = isBlocked;`
3. `public static Vector3[] FindPath(Vector3 startWorld, Vector3 endWorld)`
     – 把世界坐标转换为网格索引：
     – `Vector2Int startGrid = WorldToGrid(startWorld); Vector2Int endGrid = WorldToGrid(endWorld);`
     – `List<Vector2Int> gridPath = AStarSearch(startGrid, endGrid);`
     – 将 `gridPath` 转为世界坐标：
     – `Vector3[] worldPath = gridPath.Select(p => GridToWorld(p)).ToArray();`
     – 返回 `worldPath;`

#### 成员方法（private static）

1. `private static Vector2Int WorldToGrid(Vector3 worldPos)`
     – 假设网格中心对齐世界原点，单元格大小 `cellSize`：
     – `int x = Mathf.FloorToInt((worldPos.x + (_width * cellSize) / 2) / cellSize);`
     – `int y = Mathf.FloorToInt((worldPos.y + (_height * cellSize) / 2) / cellSize);`
     – `return new Vector2Int(x, y);`
2. `private static Vector3 GridToWorld(Vector2Int gridPos)`
     – `float worldX = gridPos.x * cellSize - (_width * cellSize) / 2 + cellSize / 2;`
     – `float worldY = gridPos.y * cellSize - (_height * cellSize) / 2 + cellSize / 2;`
     – `return new Vector3(worldX, worldY, 0);`
3. `private static List<Vector2Int> AStarSearch(Vector2Int start, Vector2Int end)`
     – A* 算法实现：
     – 维护 `openSet`、`closedSet`、每个 `Node` 记录 `gCost`、`hCost`、`fCost`、`parent`。
     – 对 8 邻域或 4 邻域进行搜索，若 `_blocked[x, y] == true` 则跳过。
     – 找到 `end` 后，通过 `parent` 回溯生成路径列表。
     – 返回 `List<Vector2Int>`。

    // …可根据需求扩展
}
```

- **Templates**：每条 Debuff 包含类型、数值、文字说明。

### 10.7 BuildingStats.json

```
json复制编辑{
  "Buildings": [
    { "Type": "Wall",         "Life": 500,  "Cost": 50 },
    { "Type": "Beacon",       "Delay": 3,   "Duration": 5,    "Radius": 3,  "Cost": 120 },
    { "Type": "AmmoStation",  "Radius": 2,  "ReloadReduction": 0.3, "Cost": 150 },
    { "Type": "Barrel",       "LifeTime": 10,"Radius": 3,    "Damage": 800, "Cost": 120 },
    { "Type": "ReflectiveWall","Cost": 100 }
  ]
}
```

- **Type**：建筑类型（Wall、Beacon、AmmoStation、Barrel、ReflectiveWall）。
- **Life**：仅用于 `Wall` 的生命值。
- **Cost**：建造该建筑所需金币。
- 对于 `Beacon`：`Delay`（激活延迟秒数）、`Duration`（持续秒数）、`Radius`（吸引半径）。
- 对于 `AmmoStation`：`Radius`（Buff 半径）、`ReloadReduction`（换弹时间减少比例）。
- 对于 `Barrel`：`LifeTime`（自动爆炸秒数）、`Radius`（爆炸范围）、`Damage`（爆炸伤害）。
