# 一、项目概述

**游戏名称（暂定）**

- 中文：**塔升纪元**
- 英文：**Tower Ascension**

**游戏类型**

- 单塔 Roguelike 塔防（塔防 + 随机构筑 + 持续挑战）

**目标平台**

- iOS / Android（Unity 2021.3 LTS 及以上）

**核心卖点**

1. **单条炮塔线路 + 多种局内建筑 + 少量主动技能**：简洁操作却有深度策略。
2. **100 回合持续闯关**：每局共计 100 回合敌潮，通关一次后需选取 Debuff（刻印规则），下一局难度叠加。
3. **随机属性升级构筑**：每回合结束后从 3 个随机属性中选一个，形成多样化流派。
4. **局外无限词条技能树**：三个阶段：功能性 → 数值性 → 词条性，满足长期成长需求。
5. **银行 & 金币怪投资机制**：让玩家在战斗节奏中兼顾“风险/收益”思考。
6. **极简未来感美术风格**：纯白矩形与线条构成塔防与建筑，低饱和度冷配色，突出科技感。

# 二、核心玩法描述

## 2.1 游戏大流程

1. **进入主界面**
   - 显示“开始挑战”“技能树”“商店”“设置”等按钮。
   - 显示玩家当前刻印点（热度值）与排名、皮肤、数据统计等。
2. **选择开始挑战 → 进入关卡**
   - 触发一局 100 回合模式。
   - 系统根据玩家之前通关次数，强制激活一定数量 Debuff 刻印（刻印会改变回合节奏或数值）。
3. **局内战斗**
   - 固定底部有若干“炮塔建造格”（初始 4 格，可通过技能树解锁到最多 6 格）。
   - 右侧有“建筑建造按钮”（初始 2 个槽位，可升级到 4 个槽位）。
   - 局内有 3 个“主动技能槽位”，可在技能树解锁额外槽或降低冷却。
   - 每回合敌人从屏幕顶部按波次出现，朝底部“核心水晶”前进。
   - 玩家操作：
     1. 在底部建造/合成炮塔（合成规则：3 个相同等级塔→1 个更高等级塔）。
     2. 在建筑槽位放置建筑：墙体、诱导信标、弹药补给站、爆炸桶、反射镜墙。
     3. 主动技能释放（如冰霜风暴、火力压制、能量屏障等）。
   - 每回合结束后：开启“随机属性升级面板”，从 3 个属性中选一个或刷新（刷新消耗金币随刷新次数递增）。购买属性后立即生效。
4. **通关与刻印**
   - 当成功守住 100 回合，即视为通关。系统记录玩家通关次数 M。
   - 下一次挑战时，系统要求玩家从 Debuff 刻印池中选择 k 个刻印，k 随通关次数递增（如通关一次选1，通关三次选2，通关五次选3 等）。
   - Debuff 刻印样例：
     - 子弹速度 −20%，
     - 攻速 −15%，
     - 墙体生命 −50%，
     - 金库收益 −30%，
     - 敌人生命 +10%，
     - 开局无金币，等等。
   - 刻印会带来额外热度值，可在商店用来兑换皮肤/称号/边框等。
5. **局外成长与重玩驱动**
   - **无限词条技能树**：
     - **第一阶段（功能性）**：解锁建筑槽位、技能槽位、商店刷新次数等。
     - **第二阶段（数值性）**：加攻速、加射程、加银行收益、加银行利率、减技能冷却、减刷新成本等。
     - **第三阶段（词条性）**：加入随机词条，如“击杀时有 10% 概率赠送金币”“建筑建造后回合返还 50% 金币”“敌人首杀降低 20% 移速”等。
   - **热度刻印系统**：每通关一次可选一个 Debuff 刻印，累计热度值可在商店换取稀有展示道具。
   - **每日挑战模式**：无刻印限制，每局通关后奖励随机词条。
6. **结束一局 → 结算界面**
   - 显示通关回合数、获得刻印点、掉落词条（若有）、触发成就。
   - 可以选择“重玩”或“返回主界面”。

## 2.2 主要角色与元素

- **核心水晶（Core Crystal）**：位于屏幕最底部中心，被怪物撞击达一定次数或破坏即视为失败。
- **炮塔（Tower）**：
  - 固定在底部一字排开的格子中。基础为 4 格，可解锁至 6 格。
  - **等级**：1–5 级，三个同等级塔合成高一级。
  - **属性**：
    - 等级1：BaseAttack=100，Range=200，AttackSpeed=1.0，CritRate=0%，CritDamage=150%
    - 等级2：BaseAttack=200，Range=230，AttackSpeed=1.1
    - 等级3：BaseAttack=400，Range=260，AttackSpeed=1.2
    - 等级4：BaseAttack=800，Range=300，AttackSpeed=1.3，解锁 1 个词条槽
    - 等级5：BaseAttack=1600，Range=340，AttackSpeed=1.5，解锁 2 个词条槽
- **建筑（Building）**：
  - **墙体（Wall）**：挡怪但不挡子弹。可升级：生命、可自愈、可穿孔、可爆破等。
  - **诱导信标（Beacon）**：放置后 3 秒激活，吸引周围怪物向它移动 5 秒，冷却 30 秒。
  - **弹药补给站（Ammo Station）**：所在半径 2 格内的塔换弹时间 −30%（本局持续生效）。
  - **爆炸桶（Barrel）**：被怪触碰后爆炸，范围 3×3 格造成 800 伤害，存在 10 秒后自动销毁。
  - **反射镜墙（Reflective Wall）**：子弹碰到它会根据法线反射一次，弹道角度固定，不可旋转。
- **主动技能（Skill）**：局内最多 3 槽可装备。需在局外技能树解锁更多槽或缩短冷却。示例：
  - **冰霜风暴（Frost Storm）**：全图减速 50%，持续 3 秒，冷却 45 秒。
  - **火力压制（Fire Rampage）**：全图伤害 +100%，持续 5 秒，冷却 60 秒。
  - **能量屏障（Energy Barrier）**：全体建筑获得护盾（吸收 X 点伤害），持续 10 秒，冷却 90 秒。
- **敌人（Enemy）**：
  - **形态**：圆形、三角形、四边形等简易几何图形。
  - **行为**：从屏幕上方直线或路径导向“核心水晶”，未到达屏幕底端时被击杀则散落金币/资源。
  - **属性**：
    - Speed（移动速度），Life（生命值），Shield（可选护盾值），RewardGold（击杀时获得金币）。
  - **变种**：可随回合推进解锁带护盾、群体分裂、远程投射、飞行免疫墙体等特殊词条。
- **银行（Bank）投资系统**：
  - 局内“存入”任意金币（以 100 的倍数为单位），银行队列中排队。
  - 默认：存入后 5 回合返还 110% 本金。
  - 可通过技能树升级：
    - 缩短返还回合（5→4→3→…）
    - 提高返还比例（110%→130%→150%）
    - 增加最大可存笔数（3→5→10）
    - “高风险账户”选项，返还回合更长（8 回合），返还比例更高（200%），失败则该笔损失。
- **金币怪（GoldGolem）挑战系统**：
  - 支付一定金币后，在场景中召唤金币怪：
    - **普通金币怪**：Cost=100，Reward=110（需在 15 秒内击杀），Speed=1.2×普通怪
    - **稀有金币怪**：Cost=200，Reward=300，Speed=1.5×普通怪，Life 更高
    - **精英金币怪**：Cost=500，Reward=900，Speed=2.0×普通怪，Life 极高
  - 若击杀成功，则奖励相应金币；若逃跑或死亡，视为失败且不返还。
  - 金币怪与普通回合怪物独立，不影响回合波次，但占据屏幕空间与注意力。

## 3.3 核心数据结构与配置

### 3.3.1 塔（Tower）系统

```
csharp复制编辑// TowerType 枚举，用于工厂生成与脚本内部区分
public enum TowerType
{
    Basic,    // 等级 1
    Level2,   // 等级 2
    Level3,   // 等级 3
    Level4,   // 等级 4
    Level5    // 等级 5
}

// Tower.cs
public class Tower : MonoBehaviour
{
    // 基础属性（修改时调用 UpdateStats()）
    public float BaseAttack { get; set; }
    public float CurrentAttack { get; private set; }
    public float Range { get; private set; }
    public float AttackSpeed { get; private set; }
    public float CritRate { get; private set; }
    public float CritDamage { get; private set; }

    // 合成后携带的“词条槽”列表
    private List<string> _affixSlots = new List<string>();

    // 动画/特效引用
    private Animator animator;
    private Transform muzzlePoint;

    // 内部计时
    private float _attackTimer;

    private void Awake()
    {
        animator = GetComponent<Animator>();
        // muzzlePoint = ...
    }

    private void Update()
    {
        _attackTimer += Time.deltaTime;
        if (_attackTimer >= 1f / AttackSpeed)
        {
            TryShoot();
            _attackTimer = 0;
        }
    }

    private void TryShoot()
    {
        // 检查是否有敌人在射程范围内
        var target = EnemyManager.Instance.FindNearestInRange(transform.position, Range);
        if (target != null)
        {
            Shoot(target);
        }
    }

    private void Shoot(Enemy target)
    {
        // 1. 播放射击动画 & 后坐力 & 炮口闪光
        AnimateRecoil();
        FlashMuzzle();

        // 2. 生成子弹或直接射线伤害
        // 以内置极简风格用“瞬移碰撞箱”即可
        var bullet = Instantiate(PrefabManager.Instance.BulletPrefab, muzzlePoint.position, Quaternion.identity);
        bullet.GetComponent<Bullet>().Initialize(this, target, CurrentAttack, CritRate, CritDamage);

        // 3. 如果触发某些词条（如击杀返还等），由子弹或 Enemy 脚本调用相应逻辑
    }

    public void UpdateStats()
    {
        // 将 BaseAttack 与全局加成、词条等综合计算得到 CurrentAttack
        CurrentAttack = BaseAttack + TowerManager.Instance.GlobalAttackBonus;
        // 如果有其它加成或词条，则继续累加
    }

    private void AnimateRecoil()
    {
        // 使用 DOTween 或 Animator 控制后坐力动画
        transform.DOLocalMoveY(-0.1f, 0.05f).OnComplete(() => transform.DOLocalMoveY(0f, 0.05f));
    }

    private void FlashMuzzle()
    {
        var flash = Instantiate(PrefabManager.Instance.BulletFlashPrefab, muzzlePoint.position, Quaternion.identity);
        var sr = flash.GetComponent<SpriteRenderer>();
        sr.color = new Color(1, 1, 1, 1);
        sr.transform.localScale = Vector3.zero;
        sr.DOFade(0f, 0.1f);
        sr.transform.DOScale(0.5f, 0.1f).OnComplete(() => Destroy(flash.gameObject));
    }
}
```

public class Enemy : MonoBehaviour
{

    {
        MoveAlongPath();
    }

    private void MoveAlongPath()
    {
        if (_pathPoints == null || _currentTargetIndex >= _pathPoints.Length) return;
        var targetPos = _pathPoints[_currentTargetIndex];
        var dir = (targetPos - transform.position).normalized;
        transform.position += dir * CurrentSpeed * Time.deltaTime;

        if (Vector3.Distance(transform.position, targetPos) < 0.1f)
        {
            _currentTargetIndex++;
            if (_currentTargetIndex >= _pathPoints.Length)
            {
                ReachCore();
            }
        }
    }

    {
        Type         = type;
        BaseLife     = baseLife;
        CurrentLife  = baseLife;
        BaseSpeed    = baseSpeed;
        CurrentSpeed = baseSpeed;
        Shield       = shield;
        RewardGold   = reward;
    }

    public void TakeDamage(float damage)
    {
        if (Shield > 0)
        {
            Shield -= damage;
            if (Shield < 0)
            {
                damage = -Shield;
                Shield = 0;
            }
            else return;
        }

        CurrentLife -= damage;
        if (CurrentLife <= 0)
        {
            Die();
        }
    }

    private void Die()
    {
        // 掉落金币
        CurrencyManager.Instance.AddGold(RewardGold);
        // 如果有“击杀返利词条”，在此触发
        if (UpgradeManager.Instance.HasEnoughLogicFor("KillGoldChance"))
        {
            // 具体实现省略
        }
        EnemyManager.Instance.UnregisterEnemy(this);
        Destroy(gameObject);
    }

    private void ReachCore()
    {
        // 撞击核心水晶
        CoreCrystal.Instance.TakeDamage(1); // 每个怪物扣除 1 点水晶生命
        EnemyManager.Instance.UnregisterEnemy(this);
        Destroy(gameObject);
    }

#### WaveManager.cs（混合生成逻辑）

```
csharp复制编辑public class WaveManager : MonoBehaviour
{
    [SerializeField] private List<Wave_SO> keyWaves;       // 按 RoundNumber 升序
    [SerializeField] private EnemyPoolConfig poolConfig;   // 随机波生成权重

    private int _currentRound = 0;
    private bool _isInKeyWave = false;

    public void StartNextRound()
    {
        _currentRound++;
        _isInKeyWave = false;

        // 检查是否为关键波
        var keyWave = keyWaves.FirstOrDefault(ww => ww.RoundNumber == _currentRound);
        if (keyWave != null)
        {
            _isInKeyWave = true;
            foreach (var info in keyWave.SpawnInfos)
            {
                StartCoroutine(SpawnBatch(info.Type, info.Count, info.Interval));
            }
        }
        else
        {
            // 随机生成普通波
            GenerateRandomWave(_currentRound);
        }
    }

    private IEnumerator SpawnBatch(EnemyType type, int count, float interval)
    {
        for (int i = 0; i < count; i++)
        {
            SpawnOneEnemy(type);
            yield return new WaitForSeconds(interval);
        }
    }

    private void GenerateRandomWave(int round)
    {
        // 查找池中对应范围的 RoundPool
        var pool = poolConfig.Pools.First(p => round >= p.RoundMin && round <= p.RoundMax);
        // 根据回合数决定数量，例如： baseCount + round * scale
        int totalCount = Mathf.CeilToInt(10 + round * 1.5f);

        for (int i = 0; i < totalCount; i++)
        {
            var type = RandomPick(pool.EnemyTypes, pool.Weights);
            // 此处可做异步等待，均匀分布在回合内 1 秒钟内生成
            SpawnOneEnemy(type);
        }
    }

    private EnemyType RandomPick(List<EnemyType> types, List<float> weights)
    {
        float sum = weights.Sum();
        float rnd = Random.Range(0f, sum);
        float acc = 0;
        for (int i = 0; i < types.Count; i++)
        {
            acc += weights[i];
            if (rnd <= acc) return types[i];
        }
        return types.Last();
    }

    private void SpawnOneEnemy(EnemyType type)
    {
        Vector3 spawnPos = GetRandomSpawnPosition();
        var path         = PathfindingHelper.FindPath(spawnPos, CoreCrystal.Instance.Position);
        EnemyManager.Instance.SpawnEnemy(type, spawnPos, path);
    }

    private Vector3 GetRandomSpawnPosition()
    {
        // 在屏幕上方随机 x，固定 y
        float x = Random.Range(-GameArea.Width / 2, GameArea.Width / 2);
        float y = GameArea.Height / 2 + 1;
        return new Vector3(x, y, 0);
    }
}
```

- **说明**：
  - **关键波**由 ScriptableObject 完全定制，可手动调整平衡。
  - **普通波**按 `EnemyPoolConfig` 从 `Pools` 中抽权重，保证随机性且随回合升级。
  - `SpawnOneEnemy` 里会立刻调用 `EnemyManager.SpawnEnemy(...)` 生成敌人并赋予 A* 路径。

    /// 玩家局内调用：存入 amount
    /// </summary>
    public void DepositGold(int amount, int currentRound, bool highRisk = false)
    {
        var record = new BankDeposit
        {
            Amount        = amount,
            RoundInserted = currentRound,
            RoundDue      = currentRound + (highRisk ? _returnDelay * 2 : _returnDelay),
            IsHighRisk    = highRisk
        };
        _depositQueue.Add(record);
        CurrencyManager.Instance.SpendGold(amount);
    }

    /// <summary>
    /// 每回合开始或结束时调用
    /// </summary>
    public void CheckMatureDeposits(int currentRound)
    {
        var matured = _depositQueue.Where(d => d.RoundDue <= currentRound).ToList();
        foreach (var d in matured)
        {
            if (!d.IsHighRisk || (d.IsHighRisk && !GameManager.Instance.IsFailed)) 
            {
                int ret = Mathf.FloorToInt(d.Amount * _returnMultiplier);
                CurrencyManager.Instance.AddGold(ret);
            }
            // 高风险失败则不返还
            _depositQueue.Remove(d);
        }
    }

csharp复制编辑public enum DebuffType
{
    BulletSpeedMinus,
    AttackSpeedMinus,
    WallLifeMinus,
    BankReturnMinus,
    EnemyLifePlus,
    NoStartGold
    // …其他
}

public class Debuff
{
    public DebuffType Type { get; private set; }
    public float Value   { get; private set; } // 例如 -0.2f、+0.1f

    public Debuff(DebuffType type, float value)
    {
        Type  = type;
        Value = value;
    }

    /// <summary>
    /// 具体调用时，这里可以运行“应用逻辑”或由 DebuffSystem 统一处理
    /// </summary>
    public void Apply()
    {
        switch (Type)
        {
            case DebuffType.BulletSpeedMinus:
                TowerManager.Instance.GlobalBulletSpeedMultiplier *= (1 + Value);
                break;
            case DebuffType.AttackSpeedMinus:
                TowerManager.Instance.GlobalAttackSpeedMultiplier *= (1 + Value);
                break;
            case DebuffType.WallLifeMinus:
                BuildingSystem.Instance.AllBuildings
                               .OfType<Wall>()
                               .ToList()
                               .ForEach(w => w.MaxLife *= (1 + Value));
                break;
            case DebuffType.BankReturnMinus:
                BankSystem.Instance.SetReturnMultiplier(BankSystem.Instance.CurrentReturnMultiplier * (1 + Value));
                break;
            case DebuffType.EnemyLifePlus:
                EnemyManager.Instance.AllEnemies
                               .ToList()
                               .ForEach(e => e.BaseLife *= (1 + Value));
                break;
            case DebuffType.NoStartGold:
                CurrencyManager.Instance.SetStartGold(0);
                break;
        }
    }
}

{
    public static DebuffSystem Instance { get; private set; }

    [SerializeField] private DebuffPoolConfig debuffPool;
    private List<Debuff> _activeDebuffs = new List<Debuff>();

    private void Awake()
    {
        if (Instance != null && Instance != this) { Destroy(gameObject); return; }
        Instance = this;
    }

    /// <summary>
    /// 游戏启动时或通关后战前调用
    /// </summary>
    public void ActivateDebuffs(int roundsCleared)
    {
        int countToSelect = CalculateDebuffCount(roundsCleared);
        var templates = new List<DebuffPoolConfig.DebuffTemplate>(debuffPool.Templates);
        for (int i = 0; i < countToSelect && templates.Count > 0; i++)
        {
            int idx = Random.Range(0, templates.Count);
            var t  = templates[idx];
            templates.RemoveAt(idx);

            var debuff = new Debuff(t.Type, t.Value);
            _activeDebuffs.Add(debuff);
            debuff.Apply();
        }
    }

    private int CalculateDebuffCount(int cleared)
    {
        if (cleared >= 5) return 3;
        if (cleared >= 3) return 2;
        if (cleared >= 1) return 1;
        return 0;
    }
}

- **方式 2：机身后仰**

  - 位移方式：`LocalMoveY:0 → -0.1 (0.05s) → 0 (0.05s)`
  - 旋转方式：`LocalRotateZ:0 → 10° (0.05s) → 0 (0.05s)`

- **方式 3：枪口闪光**

  - 在炮管顶端生成一个白色圆形 Sprite，`Scale:0→0.5` 同时 `Alpha:1→0`，0.1s 后销毁。

- **方式 4：子弹/激光条**

  - 生成一段细长白色矩形作为“弹道”飞向目标，移动 0.2s 后消失并命中敌人。
  - 可选：给子弹加 TrailRenderer 做拖尾效果。

- **组合推荐**：

  - **极简风格**：方式1 + 方式3
  - **爆发感强**：方式1 + 方式2B + 方式3 + 子弹拖尾

# 六、数值与平衡思路

## 6.1 回合与波次节奏

- **总回合**：100 回合。
- **关键波**：每 10 回合一波关键波，由 `Wave_SO` 精确配置（可包含精英怪、Boss怪或混合波）。
- **普通波**：按照 `EnemyPoolConfig` 规则随机生成。
  - 回合数越高，总生成数量越多（例如：10 + round×1.5）
  - 敌人类型按权重抽取，随着回合升级加入更强怪。
- **每回合时序**：
  1. 当上一回合敌人全部清除或到达终点后，调用 `WaveManager.StartNextRound()`。
  2. 回合开始时检查银行返还（`BankSystem.CheckMatureDeposits(currentRound)`），返还金币。
  3. 2 秒后开始生成本回合怪物（可设一个“倒计时”让玩家准备）。
  4. 该回合生成所有怪后，回合进入“战斗阶段”，直至怪全死亡或撞破水晶。
  5. 回合结束时弹出“属性升级面板”，玩家选购或跳过。
  6. UI 收起，进入下一回合。

## 6.2 数值增长与难度攀升

- **敌人生命与速度**：
  - 普通怪：每 5 回合 BaseLife 增加 10%，Speed 增加 5%。
  - 精英怪：每 10 回合 BaseLife 增加 15%，Speed 增加 7%。
- **怪物奖励**：
  - 普通怪基础奖励：Round×2 金币（随回合数递增）。
  - 精英怪奖励：Round×5 金币。
- **炮塔攻击**：
  - 装备新塔时，基础攻击值依照 `TowerStats.json` 配置再加上 `GlobalAttackBonus`。
  - 合成时，消耗 3 个同级塔，生成高一级塔：
    - 父塔1、2、3 的 BaseAttack 会累加做为子塔初始值，或直接读取 `TowerStats` 最高本级 BaseAttack，然后外加全局加成。
- **属性升级（随机流派）**：
  - 加攻速 / 加射程 / 加暴击率 / 加暴击伤害 / 增加塔子弹容量 / 减少换弹时间 等，升级数值对此刻游戏状态进行微调
  - 数值幅度示例：+10 Attack / +0.1 AttackSpeed / +0.05 CritRate / +20 Range / +0.2 CritDamage / +10 BulletCount / -0.2 ReloadTime
- **银行**：
  - 默认返还周期 5 回合，返还比例 110%。
  - 玩家通过升级可缩短周期、提高返还比例、增大可存上限。
- **金币怪**：
  - 普通金币怪 Cost=100，Reward=110，Speed=1.2×，Life=Round×?（与回合数相关）；
  - 稀有金币怪 Cost=200，Reward=300；精英金币怪 Cost=500，Reward=900，Speed=2×。
- **Debuff 刻印**：
  - 负面效果随机抽取（如 attackSpeed×0.8 / bulletSpeed×0.8 / wallLife×0.5 / bankReturn×0.7 / enemyLife×1.1 / startGold=0 等）
  - 随通关次数递增的选取数量，叠加后提高下局难度。

## 6.3 建筑与流派平衡

- **墙体**：
  - 默认为挡怪但不挡子弹，Life=500。
  - 升级后：Life 额外 +50% / 自愈慢回 / 穿孔后自爆等。
  - 建造消耗：50–100 金币不等，视升级阶段递增。
- **诱导信标**：
  - 吸引半径 3 格，延迟激活 3 秒，持续 5 秒。
  - 冷却：30 回合或 30 秒。
- **弹药补给站**：
  - Buff范围 2 格，作用为塔 ReloadTime×0.7；消耗 150–200 金币。
- **爆炸桶**：
  - 当被怪碰触或 10 秒后自爆，Radius=3 格，Damage=800；消耗 120 金币。
- **反射镜墙**：
  - 子弹反射一次，无消耗；有限存放（如 2–3 个）。

这些建筑数值需要在实测中不断调整，保证“流派”不会出现强到压抑其他流的单一套路。例如：“爆炸桶流”若太强，就要适当提高消耗或缩短爆炸伤害。

# 七、技术实现细节

本节针对 Unity 开发提供一些技术细节与注意事項，方便你团队直接落地开发。

## 7.1 性能优化

1. **路径寻路**
   - 使用网格（二维 bool[_width, _height]）标记可走/不可走区域；
   - 地图更新（添加/移除墙体）时，批量调用 `SetBlocked(x, y, true/false)`。
   - 怪物寻路：**不每帧**都寻路，而是在路径断裂时（到达上一个节点，或发现前方被阻挡）“请求一次 A* 计算”并缓存到路径点列表。
   - 关键波/普通波使用 `WaveManager` 统一生成时，即可为每个怪物同时赋值相同路径（当无墙时路径相同）。
2. **对象池**
   - 对炮塔、子弹、建筑、怪物、特效等使用对象池（Object Pool）管理，避免频繁 Instantiate/Destroy。
   - DOTween 动画和粒子特效也可考虑复用。
3. **UI 批处理与 Canvas 优化**
   - 属性面板、技能面板、UILayer 均使用单独一个 Canvas，避免频繁重绘。
   - 金币数字、波次数字等只在数值变化时刷新纹理。
4. **Update 数量控制**
   - 尽量减少脚本的 `Update()` 调用，将逻辑改为事件驱动或 `Coroutine`。
   - 怪物移动使用统一 `EnemyManager` 调度，而不是每个怪单独 Update。

------

## 7.2 数据驱动与配置

1. **JSON / ScriptableObject 配置**
   - **塔、建筑、敌人、升级模板、Debuff 刻印、关键波波次** 均使用 ScriptableObject 或 JSON 来配置，方便策划调整。
   - 例如 `TowerStats.json`、`EnemyStats.json`、`BuildingStats.json`、`UpgradeTemplates.asset`、`DebuffPoolConfig.asset`、`Wave_SO` 等。
   - 代码里通过 `TextAsset` 或 `Resources.Load`／`Addressable` 方式加载并反序列化。
2. **常量管理**
   - 在 `Utils/Constants.cs` 里定义所有 Tag、Layer、路径常量、资源地址、网格大小、最大回合数、默认金币数等，保证代码可维护性。
3. **本地存档**
   - 使用 `PlayerPrefs` 或文件 I/O（JSON）保存玩家局外**技能树进度**、**已解锁刻印**、**总通关次数**、**皮肤/称号拥有列表**。
   - 读取时按优先：`PlayerPrefs` > `本地 Json` > 默认值。

------

## 7.3 脚本编写规范

- **命名空间**：所有脚本使用 `namespace TowerAscension { ... }` 规范命名。
- **文件与类一一对应**：`UpgradeManager.cs` → `public class UpgradeManager : MonoBehaviour`。
- **事件订阅**：在 `OnEnable` 里订阅事件，`OnDisable` 里取消，避免空引用。
- **单例管理**：所有带 `Instance` 的管理类（Manager）使用简易单例实现，禁止在 `Awake` 之外重复创建。
- **日志与埋点**：关键流程（如购买升级、召唤金币怪、通关、失败）统一使用 `Debug.Log` 或统计接口 `Analytics.TrackEvent(...)`。
- **异常处理**：购买、召唤、建造等带“条件判断”时，若不满足条件需做提示，而非直接返回空指针。
- **协程管理**：避免“嵌套协程”或“无限循环协程”，结合 `TimerUtility` 简化延时逻辑。

# 九、常见问答与注意事项

1. **Q：是否支持横屏？**
   - A：本方案以竖屏为主，可后期适配横屏，需重新调整 UI 布局与触控区域。
2. **Q：是否有剧情或关卡切分？**
   - A：目前仅单一 100 回合关卡，未来可加入“章节关卡”，每隔 100 回合解锁新地图或视觉主题。
3. **Q：资源如何加载？**
   - A：建议使用 Unity Addressables 或 Resources.Load 结合 ScriptableObject 配置表，方便动态增删波次/升级模板。
4. **Q：如何保证平衡？**
   - A：
   - 使用 KeyWave SO 精确调控关键波节奏；
   - 在 Production Build 后集成“远程 Debug/Hotfix”，快速迭代数值；
   - 每回合做数据埋点，分析平均通关回合、常用升级分布。
5. **Q：UI 适配哪些分辨率？**
   - A：iOS/Android 常见分辨率（16:9, 18:9, 19.5:9），使用 Canvas Scaler 设为“参考宽度 1080”，保持纵横比适配。
6. **Q：怎样处理玩家失败后的体验？**
   - A：
   - 提示本局击杀回合数、获得热度点、解锁新刻印或新词条；
   - 可选择“用广告复活并清空场上所有怪物”或“带着部分金币重开”；
   - 失败后允许花费热度点解锁永久被动（如“开局攻速+5%”）。
